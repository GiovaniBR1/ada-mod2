# Projeto Final: PE-JV-003

Conforme combinado em aula, o projeto final é a entrega, no GitHub, dos cinco documentos de System Design das Aulas 02 a 06.

## O que entregar

Um documento por aula, preenchido a partir do template disponível nos arquivos do módulo:

| Aula | Tema | Template |
| :--- | :--- | :--- |
| 02 | APIs Resilientes | `PE-JV-003-Aula-02-Template-System-Design.md` |
| 03 | Banco de Dados em Larga Escala | `PE-JV-003-Aula-03-Template-System-Design.md` |
| 04 | Microsserviços & Padrão Saga | `PE-JV-003-Aula-04-Template-System-Design.md` |
| 05 | Containers, CI/CD & Deploy sem Downtime | `PE-JV-003-Aula-05-Template-System-Design.md` |
| 06 | Observabilidade & Diagnóstico em Produção | `PE-JV-003-Aula-06-Template-System-Design.md` |

## Como entregar

- Use o repositório que você já vem usando nas aulas.
- Cada aula fica num arquivo próprio, com as suas respostas no lugar de `[Sua resposta aqui]`.
- Deixe o repositório acessível ao professor e envie o link pelo canal indicado em aula.
